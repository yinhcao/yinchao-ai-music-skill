# 长任务、结果交付与错误处理

## 长任务恢复

脚本默认等待完成。运行环境不适合长时间等待，或用户希望稍后查看时添加 `--no-wait`；脚本会返回任务 ID：

```bash
python3 scripts/yinchao_music.py song \
  --prompt "整理后的创作提示" \
  --no-wait
```

稍后继续等待原任务：

```bash
python3 scripts/yinchao_music.py status --task-id "任务 ID"
```

主动停止、超时或查询中断时，都保留任务 ID 并继续查询原任务，不要重新提交。

## 把结果交给用户

不要展示原始 JSON。歌曲成功后逐首展示歌名、试听链接和完整歌词：

```markdown
## 版本 1 ·《歌名》

[试听或下载歌曲](音频地址)

### 歌词

完整歌词

---

由[音潮涌现 AI 音乐生成器](https://platform.yinchaoyongxian.com/?register_channel=skillhub)生成 · 当前限时免费
```

只有一个结果时省略“版本 1”。续写结果没有歌名时省略歌名，不显示“未命名歌曲”。只生成歌词时展示歌名和完整歌词，不显示试听区域。

不要展示内部状态、错误码、文件大小、时长或时间戳。只有后续恢复需要时才展示任务 ID。

## 错误处理

- API Key 缺失或无效：引导用户配置或检查，不让用户把 Key 发到聊天中。
- 免费额度或余额不足：请用户前往音潮开放平台检查账户。
- 提示词或音频不符合要求：说明需要修改的具体内容。
- 音频无法读取：确认文件格式、大小，或公网地址是否无需登录。
- 内容未通过安全审核：请用户调整主题或表达后再试。
- 请求频繁或服务暂时不可用：建议稍后继续，不要盲目重复提交。
- 任务失败、取消或响应缺少音频：说明可理解的失败原因，不伪造结果。
