# 参考音频创作

接受一种参考来源：

- 本地 MP3/WAV 文件：`--audio-file`，最大 10MB。文件会上传至音潮开放平台用于本次创作，执行前应按主说明告知用户。
- 无需登录即可访问的公网 HTTP/HTTPS 音频：`--audio-url`。
- 音潮开放平台歌曲 ID：`--audio-id`。

仅使用用户有权使用的音频。把具体艺人或歌曲要求转换成流派、年代、配器、节奏、情绪和人声质感等音乐属性，不承诺克隆声音或复刻旋律、歌词与录音。

```bash
python3 scripts/yinchao_music.py reference \
  --audio-file "/绝对路径/reference.mp3" \
  --prompt "希望保留和改变的风格、律动、结构与情绪" \
  --similarity 0.8
```

默认参考强度为 `0.8`。希望弱化参考时用 `0.2`，希望加强时用 `1.3`；只有用户明确要求尽量接近且不涉及不当复刻时才用 `1.5`。可用 `--lyric` 传入最多 3000 字符的自定义歌词。用户明确只要一首时添加 `--n 1`。
